---
title: cuby-memory CLI
icon: Terminal
---

Gives external Agents or scripts access to the Memory service:

```bash
cuby-memory init
cuby-memory health
cuby-memory search "memory policies in this project"
cuby-memory add "a piece of knowledge worth saving"
cuby-memory get <id>
cuby-memory delete <id>
```

Connects to `http://127.0.0.1:28960` by default. Use `--url`, `--token`, `--config`, `--source`, and `--user-id` to specify the target service, authentication, calling source, and user namespace.

Also supports reload-config, session open/close, turn start/complete, and raw calls.
