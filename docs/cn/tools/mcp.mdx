---
title: 自定义 MCP Server
icon: Server
---

Memmy 支持 `stdio`、`sse`、`streamableHttp` 三种 MCP server：

```yaml
tools:
  mcpServers:
    example:
      type: stdio
      command: npx
      args:
        - "-y"
        - "your-mcp-server"
      toolTimeout: 30
      enabledTools:
        - "*"
```

## 桌面端管理

桌面端「连接与工具」页的 MCP 分区提供与设置接口等价的图形界面：内置的精选预设（Brave Search、Exa，以及折叠在「开发者工具」下的 Figma、Firecrawl）可以一键安装、测试、移除；也可以填写自定义 server。所有改动写入同一份 `tools.mcpServers` 配置并自动热重载。

## 内置工具开关

```yaml
tools:
  web:
    enabled: true
    search:
      provider: duckduckgo
      maxResults: 5
    fetch:
      timeoutS: 30
      maxChars: 60000
  exec:
    enabled: true
    timeout: 60
  imageGeneration:
    enabled: false
```

内置工具覆盖文件系统、shell、Web 搜索与抓取、MCP、定时任务、消息发送、图像生成、长任务、自省、运行时状态和上下文管理。
