1.1 本协议适用于 Cuby 桌面客户端（以下简称“Cuby”或“本客户端”）以及我们通过本客户端向你提供的相关服务（合称“本服务”）。

## 2. 定义

2.1 “Cuby”指由我们提供的桌面客户端软件，包括其后续版本、更新及随附文档。

2.2 “CubeRouter”指由我们运营的账号与模型服务平台，提供平台账号注册与登录、模型访问及相关计费服务。

2.3 “平台账号”指你按照 CubeRouter 平台规则注册并用于登录 Cuby 的账号。

2.4 “模型服务”指通过 CubeRouter 平台接入的大语言模型及相关推理能力。

2.5 “记忆采集”指 Cuby 在获得你授权后，从你选择的对话、工作区或 Agent 交互中提取信息并形成记忆数据的功能；“记忆注入”指 Cuby 在后续交互中将相关记忆数据提供给 Agent 或模型参考的功能。

2.6 “改进计划”指本协议第 9 条所述、默认关闭且可随时撤回的可选计划。

2.7 “用户内容”指你通过本服务输入、上传、生成、保存或处理的文本、文件、指令、记忆数据及其他材料。

## 3. 服务内容

3.1 Cuby 是一款桌面客户端，为你提供与 Agent 交互的界面，并支持跨 Agent 共享记忆、调用工具与消息通道、访问模型服务等功能。

3.2 我们可能不时增加、调整或停止部分功能，具体以实际提供的版本为准。部分功能可能处于测试或预览状态，其稳定性与可用性可能不同于正式功能。

3.3 本服务的可用性受你的设备、网络环境、CubeRouter 平台状态及第三方服务状态等因素影响。

4.3 你应妥善保管账号、密码及验证信息，不得向他人转让、出借或共享账号，不得批量注册账号或以自动化手段恶意注册。因你保管不善造成的损失由你自行承担，但因我们的过错造成的除外。

7.1 记忆采集与注入功能仅在你明确授权后启用。未获得授权，我们不会为记忆目的采集你的对话内容。

7.3 你保证你对被采集及注入的对象享有合法权利或已获得必要授权，记忆内容不得侵犯他人合法权益或违反法律法规。
