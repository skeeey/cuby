# MCP preset logo assets

The SVG files in this directory were extracted from `@lobehub/icons-static-svg` version 1.94.0,
the same release the sibling `llm-provider-logo` directory uses.

Source: https://github.com/lobehub/lobe-icons

The package's icon ids do not always match our preset names: `brave.svg` upstream is
`brave-search.svg` here, because `brave-search` is the name this app's preset uses.

These are bundled rather than fetched at runtime. They previously resolved through
Google's favicon service, which is unreachable from some networks and left every card
blank with no fallback.
